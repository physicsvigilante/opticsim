# JEE native finite-prism + parallel Beam — feasibility research v1

**Research-only. No production schema admission or source changes.**

This protocol freezes **14 deliberately synthetic controls** before native execution. It investigates a reusable engine gap highlighted by JEE J13/J14: deterministic parallel rays incident on a finite triangular prism whose faces and internal path are chosen by unchanged pinned PhyDemo. The original JEE source does **not** supply this experiment's triangle vertex coordinates, incidence width, outside/inside indices, detector or numeric budgets. None are represented as textbook givens or a solved original answer; no Solutions material was inspected.

Baseline is production `main` merge `59b485d14ac28ca4ee97acc754a4cd207a7d33f1` with pinned native `811f508d2b070898c241a568b0c167dcb8645251`. The test starts with a *valid canonical v8 prism + SingleRay + Detector* solely to reuse the existing native `Glass` compilation, then substitutes a `type:'Beam'` object in a **raw research-only native scene** (not Opticsim canonical authoring). This substituted scene is never exported as qualified data or presented to the user as a validated public model. A deliberate combined authoring request must still throw.

The pre-execution protocol `protocol.json` freezes 14 cases: normal, vertex order reversal, translation, two index changes, density/width change, source misses, near/exact vertices, Fresnel branching, zero-depth, processed-limit stop and free space. The native runtime's real source emission and `Glass.onRayIncident` / `Detector.onRayIncident` callbacks are recorded without mutation or route inference, in raw input/report pairs. Observer comparisons use only actual returned hit points, winding-aware local normals and the independent tangential Snell/reflection **necessary condition**; they do not substitute a new tracer or certify full physical correctness.

Each input and result is saved as separate JSON with SHA-256 hashes under `test-artifacts/llm-authoring/jee-native-prism-beam-v1/attempt-*/`, as well as a full `report.json`. The CI artifact is evidence of builder execution, not independent physics review. All vertex-risk cases are untrusted even when native completes. Native undefined/truncation/stopped/error cases are independently marked incomplete. Recorded native detector crossings are sampled finite events, never an image, irradiance or a general 3D prism.

**Release path:** inspect actual outcomes first. If feasible, implement a narrow, isolated native prism/Beam schema with strict initial vertex clearance, event-observer qualification, downstream detector separation and real Chrome qualified save/reopen tests; then request **one independent physics/integration review on the final frozen production candidate**. Do not merge this test-only research or production code before the appropriate gate. No new review needed solely for a builder-only feasibility protocol.
