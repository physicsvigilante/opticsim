# Research only — native semicircular Glass + finite Beam (JEE J12 gap)

**Frozen before tests**: `protocol.json` at commit `3b9a08bbb01ae5db51fbdc0dea4aef5b64572d7e`. The frozen same-assistant PR #165 J12 assessment motivates the experiment; no archived Solutions were read for this work. J12 specifies parallel rays, a glass half-cylinder, 45° incidence and a glass index sqrt(2), but does **not** specify its physical radius, the surrounding index, a numerical source width, its finite scale or native detector geometry. The test-only radius = 100 mm, exterior index 1, beam width/density, incident-side convention and detectors are fully synthetic and **must not be attributed to the source question**.

The pinned PhyDemo native `Glass` supports a circular arc with three nodes (`arc:true` at the middle point), closed by one straight diameter. This study will verify whether a real native `Beam` hitting the flat diameter refracts and later intersects the real curved boundary, including native TIR and seam-edge behaviour. The code constructs an **unqualified research-only native scene** from the pinned engine rather than silently widening canonical v19 public authoring. Check native emitted positions, actual Glass callbacks, normal geometry, Snell invariants and diagnostic incompleteness. Captured native events are not a custom propagation model or a reconstructed image.

The fixed protocol includes 15 signed/translated/index/sampling/TIR/miss/seam/limit controls, a bounded event budget and per-case raw native inputs. It deliberately does not promise that near-junction cases will be stable; any native undefined behaviour, truncation, stop or ambiguous seam suppresses a complete-physics claim. Actual full-cylinder/3D validity, source-image interpretation, continuous irradiance, and exact original J12 TIR limits remain outside the research.

**Decision:** No production type, adapter, validator, UI or upstream changes in this PR. Require pinned Node24 CI evidence before proposing any authorable model. If feasible, make a separate narrow physics integration with strict geometry and browser checks, then fold that feature into its own coherent independent review rather than treating this same-assistant research as independent verification. PR #167 stays independently held for its review.
