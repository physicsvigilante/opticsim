# Review results submitted by Chat B

No independent Chat B result was available when this folder was established.

A reviewing ChatGPT conversation should create a separate review branch/PR adding:

`collaboration/review-results/<packet-id>/review-<reviewer-id>.md`

Use the report template in `../REVIEW-REPORT-TEMPLATE.md`. Include the exact source SHA, findings, reproduction/evidence, limitations, reviewer identity/model if known, and verdict. Do not overwrite earlier reports; use a new filename for a new head SHA or iteration.

If the review ChatGPT lacks GitHub write access, post the full report to the corresponding feature PR as a GitHub review/comment and provide its URL to the implementer. The implementer must not create a purported Chat B report from its own review. GitHub file history and PR comments establish where the report came from; they do not prove different model weights or human scientific independence.
