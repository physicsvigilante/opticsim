## Scope and JEE teaching significance

This first integration stage supports three separately typed queries with shared physical meanings:

1. Given known source, oriented infinite planar boundary, two indices, and an explicitly stated **incident angle**: a finite-angle **conditional mathematical apparent-axis intercept**, with a separately requested paraxial limit, TIR/axial/numerical refusals and `native:not-run`.
2. Given known source and **observer-side point**, oriented infinite plane and two indices: a unique ideal one-interface **analytical stationary transmitted ray**, source heading, predicted plane crossing, conditional apparent-axis intercept, paraxial comparison and fail-closed numerical classifications. This result also has `native:not-run`.
3. Given the previous observer query **plus explicit physical verification** (brightness, Fresnel policy, named native run preset, finite tangent detector length, arrival/direction tolerances): a separate **native PhyDemo SingleRay / PlaneGlass / Detector** forward trace with sampled measured hit/zero crossings, completed/hash-matched counts, physical first-event branch integrity, signed specular reflection checks and distinct native-evidence outcomes. The authoring does **not** prescribe the native ray's itinerary or treat a predicted crossing as an observed one.

**None** of these results is a verified perceived image, observer/eye model, PSF, continuous irradiance, optical power or general multi-interface inverse solver. Exactly one measured finite native detector sample is still not image formation. A measured zero is data about this particular finite detector, not invisibility. A native run that is incomplete, stale, inconsistent, numerically unqualified or without explicitly chosen physical inputs cannot be represented as a successful hit.
