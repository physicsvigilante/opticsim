# Observer distance to an axial point seen through a spherical cap

Give the cap radius and height, both indices, and the axial distance from the flat base to an observer in the exterior. The object is either an explicitly specified axial point inside the cap or the interior-side limit at the base. The base is the position origin and the axis points toward the observer. The shared spherical-interface query uses the object distance from the curved pole and the negative radius of the exit surface.

The result gives the signed conjugate relative to the pole, its absolute position relative to the base, and the observer-to-conjugate distance. The stable expression for the base position preserves the exact centre of a hemisphere and the equal-index identity.

For A27 the 3 cm cap and glass index 1.6 give a virtual conjugate 75/31 cm behind the pole in unit-index air. The observer is 5 cm in front of that pole, so the tabletop appears 230/31 cm away, about 7.42 cm. The public native cap checks a physically displaced source inside the glass.
