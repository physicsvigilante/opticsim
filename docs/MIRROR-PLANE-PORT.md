# Axial conjugates through a plane in front of a concave reflector

Supply the point object's depth, mirror pole depth and spherical radius in one unit. Both depths are measured from the plane, positive into the object medium. The two materials need explicit refractive indices. This model uses a real axial object, a concave mirror, a homogeneous interior and a single plane refraction into the exterior.

The direct branch scales the source depth by nExterior/nInterior. The reflected branch first forms the Gaussian mirror conjugate with object distance equal to the mirror pole depth minus the source depth. Subtract that conjugate distance from the mirror pole depth to find the signed coordinate in the interior model. Refraction scales the resulting signed coordinate by the same index ratio. Negative depth gives a real exterior focus and positive depth gives a virtual apparent position. At an exact mirror focal setting, refraction preserves the collimated output. At an exact plane conjugate, the coordinate is zero. Each branch is independently requested, so an uncertain reflected result can coexist with an available direct result.

For A28 the bubble is treated as a small point scatterer and the exterior index is set to one. The direct position is 10/3 cm into the hemisphere. The singly reflected paraxial branch is collimated because the object lies at the mirror focus. The native study measures the residual slopes of finite rays separately.
