## Shared-file integration boundaries

1. The composition catalogue now has **22** profiles, including distinct v20 and v21 versions. Each saved format validates as declared; historical v1-v19 scenes never migrate or gain optional fields. New authoring chooses one contract by component types. Invalid mixtures are refused without fallback.
2. v20 `ideal-lens` has required `y`; older lens schemas retain their exact canonical `x,focalLength,apertureHeight` and the same old native endpoints centred on zero. No v21 semicircular schema accepts a v20 lens.
3. The pin's native Beam/IdealLens/Glass/Detector algorithms are unchanged, and observations wrap real callbacks exactly once. v20 checks first- and second-lens rim ambiguity before execution; native determines genuine finite misses. v21 checks only initial straight-line flat-face clearance and watches all real later glass hits for seam/tangent/unclassified risk, invalidating native measurements on uncertainty.
4. Existing source and detector run budgets remain enforced. `simulationComplete` alone does not qualify stale, stopped, truncated, undefined or wrongly attributed evidence; all requested native readings are suppressed. Detector event lists are unavailable above the 32-event cap.
5. The source-backed original J19/J12 facts remain distinct from synthetic f,d,radius, material/exterior-index, beam and detector controls used to run an actual native illustration. The reduced coaxial lens query is not misapplied to decentered optics, and the 2D semicircular model is not asserted to solve a complete half-cylinder's TIR question.
