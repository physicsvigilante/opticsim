## Original source, missing facts, and geometric scope

The held JEE 20-problem source review at PR #165 identifies J02 as `08_Ray_Optics_Explanations/01_Reflection_at_Plane_Surfaces/Problems/008.png`: three equal-length plane mirrors AB, BC and AC form a closed **equilateral triangular enclosure** containing an object O. The question asks how many images form. The supplied text and diagram do not give numerical mirror length, exact object coordinates, emission brightness, observer position, reflection-order cutoff, or physical optical losses. No Solutions are opened.

The source-backed protocol was committed **before implementation** at `1247be259b50f6654e4af1aff138de713966e3fe` on independently reviewed `main` `a4f8502ec4b9c900079ac40b35d102cb36fccb93`. Its `research/jee-j02-mirror-orbits-v1/frozen-protocol.json` distinguishes formal mathematical candidates, finite physical mirrors, and sampled PhyDemo rays.

For *ideal infinite supporting mirror lines*, the three reflections of an equilateral triangular enclosure form an infinite affine reflection group. A constructive four-face word `AB → BC → AB → CA` acts on every point as a **nonzero planar translation**. Repeating this word produces infinitely many distinct formal image points. This mathematical classification is independent of the absolute triangle size or an interior source coordinate and is the only result admitted for source-only structural J02 facts.

**Important:** that is **not** proof that infinitely many images are physically visible from a particular observer through the three *finite* mirror segments, or that a finite native ray tracer has detected infinitely many images. Some textbook-style two-mirror-pair counting rules may report a finite count by limiting which reflection families are considered; this API does not silently apply one of those conventions or grade the original textbook's answer.

Independent mathematical references include H. S. M. Coxeter's *Discrete Groups Generated by Reflections* (1934), which explicitly describes three upright equilateral-triangle mirrors yielding unlimited formal candle images, and the standard affine reflection group of type Ã₂. ## Standalone analytical query: two explicit modes

The original source-only request, `examples/jee-j02-three-mirror-formal-orbit-v1.json`, is:

```json
  "topology": "three-equal-sides-enclosing-object",
  "reflectionPolicy": "unlimited-ideal-reflections"
}
```

It returns a **conditional mathematical unbounded-orbit classification** with `physicalVisibleImageCount:null`, `native.status:'not-run'`, and **no made-up coordinates or finite image count**.

The separate **explicitly authored synthetic coordinate** request, `examples/jee-j02-three-mirror-synthetic-points-v1.json`, adds `kind:'equilateral-three-mirror-bounded-formal-points'`, three `vertices` A,B,C, an `source` point strictly inside, and `maxReflectionOrder` from 0 through 8. All coordinates are in **mm**: sides must be equilateral within 1e−9 relative tolerance and 10–2000 mm long; source must be strictly inside at least 0.01 mm from supporting lines; coordinates stay inside ±10,000 mm. The helper reflects *mathematical point candidates* through infinite supporting lines, deduplicates positions with a fixed 1e−7 mm tolerance, and returns only **finite-depth formal positions**, first-depth layers, and the independently checked nonzero translation witness. This list never pretends to be a complete count of physically visible images or a set of verified finite-reflection light paths.

Both modes are **strict JSON queries**, not `opticsim-problem-v1` native scenes. Unknown fields, omitted vertices for numeric mode, non-equilateral geometry, outside/on-mirror sources, excessive reflection depth, malformed units or false native/image claims are refused.

## Separate pinned PhyDemo native feasibility

`test/jee-j02-three-mirror-native-research.test.mjs` uses genuine pinned PhyDemo `Mirror` segments with finite AB,BC,CA endpoints and a **synthetic SingleRay** emitter strictly inside the triangle, not the original question's unspecified physical illumination. It records actual reflection callback hit points, directions, native completion/truncation/stopping and a bounded finite event sequence; it never changes a ray, invents a virtual image, or uses an image count to qualify native results. Source position, launch direction 17°, relative brightness 0.08, 140 mm triangle, depth limit 0/3/8, translations and rotations are **added experimental parameters**. Full native Fresnel, actual pupil observation, ray-bundle power and an arbitrary-ray visibility theorem are not claimed.

Since the source is inside a 3-mirror enclosure, genuine repeated rays can hit the native interaction depth limit. That is **incomplete native propagation**, not an image count, and a finite 0-hit detector should never establish lack of visible images. A finite event count should never be extrapolated to an unbounded mathematically formal orbit.
