# Draft v25 — bounded native gradient-index rectangle with numerical qualification

**DRAFT engineering specification, no independent clearance, no merge.** Production baseline `dcdaf6361a1aea151b15cde925d27ea9fe39ad9e` (post-PR185 research). This is an additive, *strictly isolated* new schema, not a migration of historical v1–v24.

## Why now
The frozen JEE J09 source describes a continuously graded refractive medium. Previously merged PR184/PR185 research proved genuine pinned native `GrinGlass` propagation, one passive external detector crossing and controlled Euler-step convergence for a **synthetic** physically positive index field. They did NOT establish the original J09 source geometry, external index, spatial unit, grazing launch, symbolic exit or arbitrary GRIN equation validity.

## Proposed public bounded physical contract (v25)
- Exactly one ordinary `point-source` with explicit native `single-ray` mode and direction 0°; **source begins strictly inside** a finite rectangular GRIN region, on the declared reference horizontal axis. Exactly one passive **external vertical** detector is placed beyond the right material boundary. No other optics or sources.
- One new `graded-index-rectangle` component with *all authored* physical numerical parameters: `leftX,axisY,spanX,upHeight,downHeight,indexSquaredAtAxis,gradientLength,outsideIndex,partialReflection`, in explicit input `lengthUnit`. Canonical scene is millimetres. The only initial field family is **n(y)² = A + (y - axisY)/L**, with **A=1.5, L=1 mm and outsideIndex=1** explicitly supplied; arbitrary analytic strings/functions and wavelength dependence are not admitted. The squared base index is dimensionless, not a lens focal length. Native y-down conversion is a fixed trusted `\\sqrt{1.5-y}` expression using the native GRIN origin at (leftX, −axisY). No user text reaches the expression parser.
- Source coordinates and detector positions remain editable *within strict bounds*, but all other field/index, Fresnel and numerical policy choices are version-sealed for the first release. `partialReflection=false` is mandatory and explicitly approximates away Fresnel partial branches, not native TIR.
- Start with `spanX` 0.8–1 mm, `upHeight` 0.7–0.9 mm, `downHeight` 0.2–0.4 mm, and all region/source/detector positions within |x|,|y| ≤ 500 mm. The entire rectangle has n²≥1.1 and ≤2.4, so n is real and ≥1. Source lies on axis at least 0.1 mm from left face, at most 0.3 mm from it, and detector is vertical at 0.2–0.3 mm after right face with enough aperture to include the computed non-grazing ray and with ≥0.1 mm end clearance. No ray route through a more complicated system is inferred.
- Fixed `native-grin-fine-v25` numerical policy: `stepSize=0.0025 mm`, `maxRayDepth=1024`, `processedRayLimit=2048`, deterministic native `SingleRay`. Only schema 25 may use this depth. No other source/material profile gains that budget.

## Mandatory native qualification
The new v25 observer wraps **only instance-local native GrinGlass and Detector callbacks** after ordinary source/detector observers. It must delegate to each preexisting native callback once, with identical arguments and return value; never trace, resample, step, steer, repair or render a ray. It records actual bounded native `GrinGlass` callback coordinates and the actual detected point.

For every observed internal point at physical (x,y), compare its measured y against the *independent continuous-field first integral* y−axisY=(x−sourceX)²/(4 A L), with A=1.5 and L=1 mm, under the explicit horizontal source. At the vertical right boundary the true conserved horizontal momentum gives `sin(theta_out)=(rightX−sourceX)/(2 sqrt(A) L)` for outside n=1; its linear external continuation predicts the single detector crossing. Require **one real detector hit**, no off-axis/extra native branches, finite callbacks under a small cap, zero native errors/truncation/undefined behavior and both continuous-path and detected-position discrepancies ≤ **0.002 mm**, a conservative observed-accuracy gate for this setup, not a universally certified error bound.

A missing or ambiguous callback, unexpected second ray, position outside the bounded geometry, singular index domain, numerical discrepancy above threshold, audit fault or budget exhaustion must add a **fatal qualification error**, even if pinned PhyDemo emits `simulationComplete`. The CLI, native observables and browser withhold *all qualified measurements* on such failure; diagnostics can retain clearly labeled raw partial counts. Stale scene SHA/revision still suppresses all results. Do not silently downgrade to any other schema. No new image detection or continuous irradiance.

## Integration and test gates
1. New standalone native module/guard unit tests with direct pinned `GrinGlass` callback verification, source/detector reference and changed-material/geometry refusal.
2. Shared composition and contract validation; standalone authoring, genuine CLI, output snapshot hashes, stale/revision gating, and genuine real Chrome physical edits/reopen. All prior v1–v24 suites must remain green.
3. Native numerical negative control: a **test-only** deliberately coarsened step (.04 mm) may produce raw native completion, but the strict v25 observer must flag its numerical discrepancy and prevent qualified detector readings. No production user can request this coarse step in v25.
4. Verify exact Git head/tree identity, full CI and artifacts. Publish a single consolidated independent physics/numerical/integration review before merging v25; do not require reviewers to redo the unchanged PR184/PR185 research.

**Nonclaims:** Not a general GRIN expression language, J09 original grazing-incidence solution, physical image, quantitative radiometry, whole arbitrary-mixed optics engine, 3D simulation, or proof that native Euler is globally error-bounded. This first candidate is a cautious single-bounded-family capability.

## Presentation-only optics visibility

The native region is about 1 mm wide; historical default 2× rendering was only two screen pixels. **Only schema v25** may default to 80 CSS pixels/mm and accept a camera zoom of up to 100 while retaining the unchanged physics and fixed Euler step. The live Fit control uses the actual stage dimensions to show the full real GRIN rectangle and detector endpoints. Older schemas retain their original zoom bounds, auto-fit and pan behavior. These are purely presentation transformations: no ray resampling, altered refractive index or newly certified measurement can follow from zooming. Real Chrome checks must show the magnified physical region and unchanged source-bound native hit evidence.
