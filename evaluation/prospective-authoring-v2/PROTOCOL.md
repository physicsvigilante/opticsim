# Opticsim prospective authoring study v2

This is a same-assistant prospective development trial, **not** an independent-model evaluation.

1. Commit the policy and selector without opening questions. First run reads ZIP central-directory filenames/sizes and tracked full-path exposure only; it never decompresses a question.
2. Commit the exact selection.json and exposure-register.json produced by stage one. Only then extract the frozen eight Problems PNGs; never read Solutions or replace questions.
3. Record one first interpretation per image, including stated physical facts, unknowns, requested results and exact image hashes. Seal those first interpretations in a separate commit before deterministic execution.
4. Run the existing problem workflow without retries, substitute apparatus, or altered physics. Preserve missing facts, unsupported methods, native failures and fidelity checks independently. Review interpretations later without editing first attempts.

The seed-ranked one-per-section sample is not representative and tracked-path exclusions cannot prove prior nonexposure. Selecting from a public archive is not a certified unseen benchmark. No external model API call or reference-answer access occurs in the staging workflow. The pinned PhyDemo core, source ZIPs, previous trial records and shared viewer are unchanged.

This temporary lightweight GitHub workflow has no native setup, full Node suite or browser. It runs only when the fixed policy or selection changes; remove it from the final integration PR once records are sealed.
